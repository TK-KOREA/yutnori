# 윷놀이 한마당

아이와 가족이 한 화면에 둘러앉아 즐기는 3D 윷놀이입니다. 설치 없이 브라우저에서 바로 열립니다.

**바로 하기: https://tk-korea.github.io/yutnori/**

휴대폰·태블릿에서는 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 설치할 수 있습니다.

## 무엇이 재미있나요

- **설빔 입은 동물 친구들**: 말은 팀색 저고리를 입은 동물 8종(말 모모, 돼지 도야, 개 복실이, 양 몽실이, 소 누렁이, 호랑이 어흥이, 토끼 옥토, 닭 꼬꼬)입니다. 도·개·걸·윷·모가 돼지·개·양·소·말을 뜻한다는 것도 저절로 배웁니다.
- **말이 살아 있어요**: 한 칸씩 콩콩 뛰며 숫자를 세고, 업을 때는 정말 등에 업히고, 잡히면 별을 보며 "다시 올게!" 하고 집으로 돌아갑니다.
- **윷 던지는 맛**: 버튼을 누르거나, 꾹 눌러 힘을 모으거나, 멍석을 위로 쓸어 던집니다. 마지막 윷가락이 흔들리다 멈추고, 윷·모는 느린 화면으로 보여 줍니다.
- **가족 잔치판**: 🎁 선물 상자, 🎴 가족 미션(30장), 🚪 도깨비 문, 🐦 까치 소식, 💧 웅덩이, 🤝 친구 부르기 칸이 있습니다. 미션은 "옆 사람 칭찬하기"처럼 몸과 마음을 쓰는 놀이입니다.
- **모두가 상을 받는 시상식**: 1등 트로피와 함께 잡기왕, 행운왕, 업기왕, 거북이상 같은 상을 팀마다 하나씩 받습니다.
- **읽어 주기**: 차례와 결과를 한국어 목소리로 알려 줘서 글을 몰라도 따라올 수 있습니다.
- **진짜 윷으로도**: 집에 있는 윷을 던지고 나온 결과만 누르면 됩니다.
- **컴퓨터 친구**: 살살·쉬움·보통·어려움 네 단계.
- **오프라인**: 한 번 열면 홈 화면에 설치해 인터넷 없이도 할 수 있습니다.

## 규칙

전통 규칙을 기본으로 합니다. 모·뒷모·방에 멈추면 지름길, 빽도는 온 길로 한 칸 뒤, 윷·모·잡기는 한 번 더, 참먹이를 지나야 완주입니다. "어른용 규칙"에서 빽도, 완주 방식, 낙, 경기 끝 방식, 윷 확률을 바꿀 수 있습니다.

키보드: 스페이스 던지기, 1~4 선택지 고르기, ←→ 결과 바꾸기, U 되돌리기.

## 만든 방법

빌드 과정이 없는 정적 사이트입니다. HTML·CSS·자바스크립트 모듈과 [three.js](https://threejs.org/) 0.185.1(MIT, `vendor/`에 포함)로 만들었고, 그림·소리는 모두 코드로 그립니다.

| 경로 | 내용 |
| --- | --- |
| `js/rules.js` | 규칙 엔진(순수 함수) |
| `js/ai.js` | 컴퓨터 상대 |
| `js/party.js` | 잔치 칸과 가족 미션 |
| `js/game.js` | 경기 진행, 되돌리기, 저장, 시상 |
| `js/characters.js` | 동물 말 캐릭터와 연출 |
| `js/sticks.js`, `js/fx.js` | 윷가락·멍석, 색종이 효과 |
| `js/board.js`, `js/scene.js` | 윷판과 3D 장면 |
| `js/audio.js`, `js/voice.js` | 합성 효과음, 한국어 읽어 주기 |
| `js/ui.js`, `js/main.js` | 화면과 연결 |
| `tests/` | 브라우저 테스트 |
| `docs/` | 설계와 구조 문서 |

로컬에서 실행하기:

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000/`을 열고, 테스트는 `http://localhost:8000/tests/`에서 확인합니다.

배포 전에는 `python3 tools/stamp.py`로 오프라인 캐시 버전을 갱신합니다.
