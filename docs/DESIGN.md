# 윷놀이 한마당 3D — 설계 요약

전체 설계문서는 Claude 문서로 작성했고, 이 파일은 저장소에 남기는 요약입니다.

## 목표

아이·부모·조부모가 태블릿이나 TV 한 화면에 둘러앉아 즐기는 웹 윷놀이. 핵심 한 줄은
"글자나 규칙을 몰라도 5분 안에 함께 웃으며 놀 수 있는 윷놀이"입니다.

디자인 원칙

1. 읽지 않아도 알 수 있게: 그림·색·소리·음성으로 다음 할 일을 알려 준다.
2. 모든 사건에 반응: 던지기·업기·잡기·완주마다 캐릭터가 표정과 몸짓으로 반응한다.
3. 전통은 정확하게, 재미는 선택으로: 기본은 전통 규칙, 잔치 칸·미션은 켜고 끄는 옵션.
4. 진 팀도 즐겁게: 시상식에서 모든 팀이 상을 하나씩 받는다.
5. 크게, 적게: 누를 곳은 크고 적게, 되돌리기는 언제나.

## 말 디자인

팀색 저고리(몸통 공통) + 동물 머리 + 앞발 두 개. 팀은 색(다홍·쪽빛·노랑·청록, 명도 4단계),
받침 모양(●■▲★), 가슴의 흰 팀 도장, 저고리 무늬로 구분해 색각 이상이어도 알아볼 수 있습니다.

## 잔치 모드

| 칸 | 이름 | 효과 |
| --- | --- | --- |
| 4 | 선물 상자 | 한 번 더 40% / 두 칸 앞 35% / 한 칸 앞 25%. 꼴찌 팀은 늘 한 번 더 |
| 7, 16 | 가족 미션 | 미션 카드. 해내면 한 칸 앞으로, 못 해도 벌칙 없음 |
| 9 | 도깨비 문 | 가운데 방으로 순간이동 |
| 12 | 까치 소식 | 한 번 더 던지기 |
| 18 | 웅덩이 | 한 칸 뒤로 |
| 26 | 친구 부르기 | 집에 있는 우리 말을 불러 업기 |

말이 멈췄을 때만 발동하고, 한 번 발동한 칸은 모든 팀이 한 번씩 할 때까지 쉽니다. 이벤트끼리 이어지지 않습니다.

## 검증

- 규칙·컴퓨터·경기 진행 테스트(`tests/`): 컴퓨터끼리 수백 판을 두며 한 칸에 두 팀이 함께 있지 않은지, 모든 판이 끝나는지 확인합니다.
- 어려움 컴퓨터가 쉬움을 60% 넘게 이기는지 확인합니다.
- 되돌려도 윷 결과가 같은지(씨앗 난수) 확인합니다.
- 소리는 오프라인 오디오로 렌더해 무음·클리핑이 없는지 확인합니다.
